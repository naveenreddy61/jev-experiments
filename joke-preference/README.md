# joke-preference

Can a System One model become a personal joke recommender when the only thing
we train is the text of its rubric?

- **Scorer:** TypeSafe AI's Jev, `Score` primitive. One full joke per call,
  a fixed question, and three level descriptions: bad, good, great.
- **Signal:** one person's labels on 412 punchlines across 120 premises.
- **Optimizer:** GEPA, from the standalone `gepa` package. It rewrites the
  three level descriptions from per-joke feedback. DeepSeek is the reflection
  model. No LLM runs at inference time.

Design notes and the research behind them are in
[`docs/research/synthesis.md`](docs/research/synthesis.md).

## Quick start

Requires Python 3.12+ and [uv](https://docs.astral.sh/uv/).

```bash
cd joke-preference
uv sync                       # creates .venv with typesafe_sdk and gepa
uv run joke-pref label        # open http://127.0.0.1:8765 and label
```

Type your first name on the page. For each punchline pick **bad**, **good**
or **great**. Keys `1` `2` `3` label the next line, `n` moves on. Your labels
go to `data/labels/<name>.jsonl`, which is gitignored. Nothing leaves the
machine.

Everything below needs API keys in the environment:

```bash
export JEV_API_KEY=...        # TypeSafe AI
export DEEPSEEK_API_KEY=...   # only for `optimize`
```

```bash
uv run joke-pref stats                                   # label counts
uv run joke-pref split --user naveen                     # 58/17/25 % by premise
uv run joke-pref evaluate --user naveen --split test     # seed criteria on test
uv run joke-pref optimize --user naveen --max-metric-calls 400
```

By default `optimize` shows 12 premises per reflection step and asks DeepSeek
to rewrite all three levels in one call, so the levels stay distinct.
`--per-level` uses GEPA's own one-level-per-step proposer instead.
`--shuffle-labels` is the null check: it shuffles the labels inside each
train and val premise, so any test gain it shows is generic joke quality,
not personal taste. Compare a real run against it and against
`criteria/probe/a-generic.json`, the non-personal default.

`optimize` writes the run to `results/<user>/gepa-<stamp>/` with the best
criteria, the reflection log, and a test evaluation of the seed and the best
criteria side by side. Jev answers are cached in `results/jev-cache.sqlite`,
so a repeated evaluation costs nothing.

## Before labeling: does criteria text move Jev at all?

```bash
uv run joke-pref probe --n 20        # 5 criteria files x 20 jokes = 100 calls
```

The five files in `criteria/probe/` describe five different tastes. On
2026-09-19 the same joke moved by 1.33 on the 0 to 2 scale on average between
criteria, with zero invalid answers. There is something to steer.

## Layout

```text
criteria/seed.json          the starting rubric GEPA edits
criteria/probe/             five contrasting rubrics for the sensitivity probe
data/premises.jsonl         120 premises, 412 punchlines (committed)
data/raw/part-*.jsonl       the four generated parts, merged by scripts/build_dataset.py
data/labels/<user>.jsonl    personal labels (gitignored)
src/joke_pref/
  data.py                   premises, labels, splits
  criteria.py               criteria file <-> GEPA candidate
  scorer.py                 Jev Score calls, cache, error policy
  metric.py                 per-premise score and split summary
  adapter.py                GEPAAdapter and the reflection prompts
  reflection.py             DeepSeek reflection LM
  runs.py                   evaluate and optimize
  label_server.py           the labeling page (stdlib http.server + htmx)
  cli.py
tests/                      32 offline tests, fake SDK, no keys needed
results/                    runs and cache (gitignored)
```

## The metric

The unit is a premise. For each premise:

- **concordance**: share of punchline pairs with different labels that Jev
  orders the same way the person did. Ties count one half.
- **agreement**: mean probability Jev puts on the person's level.
- premise score = 0.6 concordance + 0.4 agreement.

The summary also reports exact-level accuracy, mean absolute error of the
expected score, Spearman correlation, and top-1 hit rate: does the punchline
Jev scores highest carry the person's best label?

## Data

The premises and punchlines were generated by four Opus agents, each with six
domains, six setup formats, and fourteen punchline styles. Quality was mixed on
purpose and is not recorded anywhere. Every punchline carries a `style` tag
that Jev never sees; it exists so we can later ask which styles the evolved
criteria learned to name.

## Jester

`scripts/fetch_jester.py` downloads the Jester data. `joke-pref
jester-evaluate --criteria X` scores the 100 jokes with one rubric and
reports per-user concordance for 7,200 users next to the crowd and kNN
ceilings. See `docs/jester-signal.md` and `docs/jester-results.md`.
